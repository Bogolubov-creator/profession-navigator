# Проверка рабочего приложения

Проверки выполняются на локальном сервере Node.js 24, SQLite и реальных браузерах Playwright. Это не доказательство серверного HTTPS-развёртывания или проверки физического телефона.

## Сервер

`npm test`: 10/10 проверок прошли. Проверены 65 источников, 8 075 блоков, 14 направлений, поиск GD-A-01, закрытый доступ к журналистике и заполненному образцу, запрет административного API читателю, точное совпадение скачанных форм гендиректора, логиста и НКО с SHA-256.

Проверены независимые данные двух пользователей; прогресс, избранное, личная задача и прочтение уведомления сохранились после остановки и повторного запуска процесса и нового входа. Проверены изменение, скрытие, публикация, конфликт версий 409 и повторный импорт без потери редакторской правки.

CSRF-запрос без токена отклонён. Попытка опубликовать редакционное задание, даже сменив его тип, отклонена. Импорт отклоняет путь за пределами комплекта, символическую ссылку и неподдерживаемый EXE. Произвольная HTTP-загрузка и распаковка архивов отсутствуют; исходные архивы сохраняются закрытыми, используются заранее распакованные вложения. HTML из документов выводится текстовыми узлами React, без dangerouslySetInnerHTML.

Резервная копия создана через VACUUM INTO вместе с файлами и SHA-256. Восстановлена в новый каталог, SQLite integrity_check вернул ok. Docker не проверялся.

## Браузер

Chromium: каталог, поиск, карточка, шаг, обновление прямой ссылки, PDF, отметка выполнения после перезагрузки, избранное, создание личной задачи, вход читателя/редактора, 16 редакционных задач журналистики, сохранение и повторное открытие редакторской правки прошли.

Ширины 320, 390, 768, 1024, 1440: горизонтального переполнения главной страницы нет. Сделаны и просмотрены снимки компьютерного каталога, мобильной версии, инструкции и редактора. Клавиатурный фокус доступен. Найденный недостаточный контраст подписей исправлен. Счётчики и сообщения об отсутствии материалов получены из данных, не нарисованы для демонстрации.

## Публикация

Публичное зеркало строится отдельно с отключёнными пользовательскими функциями. В нём только разрешённый снимок и 13 форм. Полный комплект, база, пароли, исходные задания, альтернативные версии, заполненный образец и референсные скриншоты исключены из git. Итоговая проверка Pages и приглашения фиксируется в DEPLOYMENT.md после публикации.

## Границы

Юридическая актуальность не проверялась. Полная автоматическая реконструкция границ и двух колонок PDF-гидов не завершена; сохранён весь текст с конкретной очередью проверки. Сложные развилки редактируются структурно. Внешние сервисы помечены как не проверенные на доступность. Проверка доступности браузерным инструментом не заменяет аудит со скринридером. Production-нагрузка, почтовая доставка и физические мобильные устройства не тестировались.

## Дополнительная итоговая проверка

Все 157 опубликованных локальных страниц открыты в Chromium: ошибок JavaScript нет. Автоматический axe-аудит главной локальной страницы после исправления контраста: 0 нарушений. WebKit проверил мобильное меню, каталог, прямую ссылку на шаг после обновления и отсутствие переполнения инструкции. Отдельная проверка вредоносного HTML: img/onerror и script отображаются текстом, исполнение отсутствует. npm audit для рабочих зависимостей: 0 известных уязвимостей на момент прогона.

Внешнее зеркало проверено без авторизации. 13/13 публичных файлов совпали по SHA-256. Проверки адреса и приглашения описаны в DEPLOYMENT.md. Автоматический аудит зеркала выявил ещё одну подпись с недостаточным контрастом; её цвет исправлен в финальном коммите и повторно проверяется после обновления Pages.
