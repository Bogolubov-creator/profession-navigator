# Проверка приложения

Локальная проверка 21.09.2026: Node.js 24, SQLite, Playwright Chromium и WebKit. Это проверка программных сценариев, не юридическая экспертиза и не испытание физического телефона.

## Сервер и данные

`npm test`: 20/20 проверок. Проверены роли, CSRF, запрет публикации заданий и закрытых файлов, раздельные пользовательские данные, подписочный доступ и его отзыв, обращения по персональным данным, выгрузка, удаление, прекращение сессий, повторный импорт, конфликт версий и сохранение после перезапуска. Проверены резервная копия и восстановление в новый каталог.

Исправлены при аудите: неверный текущий шаг отклоняется; изменение роли отсутствующего пользователя возвращает 404; перестановка шагов сохраняет адресатов развилок, удаление адресата удаляет развилку. Добавлены проверки этих случаев.

65/65 исходников и 13/13 публичных файлов совпадают с реестром SHA-256. Снимок публичного каталога проверен на отсутствие закрытых источников, заданий, примеров и текущих паролей. Проверен импорт публичного каталога в новую базу. `npm audit --omit=dev`: 0 известных уязвимостей на момент проверки.

## Браузеры

Chromium открыл все 303 публичные страницы без ошибок JavaScript. Проверены поиск, карточка, шаги, прямая ссылка после обновления, PDF, скачивание форм, избранное, личная задача и сохранение отметки. Проверены создание пользователя, запрос и выдача доступа, кабинет, выгрузка и удаление тестовой записи. В WebKit повторены сценарии кабинета и подписки.

Проверены все 14 профессий: список, первая карточка, следующий шаг, перезагрузка прямой ссылки. Явное переключение «Автоматически / Мобильная версия / Полная версия» проверено в Chromium и WebKit на широком экране и в мобильном контексте 390 px. Выбор сохраняется после обновления. На ширинах 320–1440 px проверенные страницы не имеют горизонтального переполнения.

PWA: manifest standalone, регистрация service worker и офлайн-экран проверены в Chromium. Кэш содержит только offline.html; личные данные и каталог не кэшируются. Установка на физический iPhone или Android не проверялась.

Автоматическая проверка axe каталога, кабинета и админки подписок: без замечаний в проверенных состояниях. Отдельный XSS-сценарий подтверждает, что HTML и script показываются текстом и не исполняются. Полный аудит со скринридером не проводился.

Расширенный сценарий админки прошёл: создание карточки и шага, повторное открытие, сравнение и восстановление версии, копирование в черновик, сохранение чек-листа, 14 профессий, просмотр оригинала, предварительная проверка импорта и загрузка ролей.

## Повторение

```sh
npm test
npm run test:browser
npm run test:accounts-browser
QA_BROWSER=webkit npm run test:accounts-browser
node scripts/layout-browser-qa.js
QA_BROWSER=webkit node scripts/layout-browser-qa.js
node scripts/admin-browser-qa.js
node scripts/pages-browser-qa.js
npm run test:xss
```

Тесты API и браузерной редакторской работы использовать на тестовой копии, если в базе появились реальные пользователи. Служебные записи расширенного теста админки удаляются после прогона.

## Границы эксплуатации

Публичный сервер с базой не развёрнут; приложение с аккаунтами работает локально. Зеркало GitHub Pages предназначено только для чтения. Онлайн-платежи не подключены: доступ выдаёт администратор на срок по заявке. Перед промышленным запуском оператору нужны утверждённые политика, сроки хранения, реквизиты для обращений и подтверждённое размещение данных. Наличие функций обработки обращений не является подтверждением полного соответствия 152-ФЗ.

Не проверены промышленная нагрузка, Docker, почтовая доставка, реальный эквайринг и физическая установка PWA. Правовая актуальность материалов требует отдельной проверки. Пробелы источников перечислены в CONTENT_AUDIT.md.
