# Публикация и доступ

Репозиторий: https://github.com/Bogolubov-creator/profession-navigator

Публичное зеркало: https://bogolubov-creator.github.io/profession-navigator/

Полное локальное приложение: http://127.0.0.1:4317/#/login

Зеркало публикует GitHub Actions через Pages. Снимок содержит 303 материала для 14 направлений и 13 разрешённых файлов. На зеркале работают чтение, поиск, шаги, скачивание и выбор мобильной/полной версии. Вход, общая база, личный план, подписки и администрирование работают в серверном приложении. Внешний сервер с постоянной базой ещё не развёрнут.

В GitHub не входят исходный архив, закрытые материалы, база пользователей и пароли. Свежий клон запускается с публичным каталогом через `node scripts/seed-public.js`, затем `npm run setup`, `npm run build` и `npm start`. Случайные пароли создаются локально в `private/credentials.json`. Полный редакторский архив передаётся отдельно по закрытому каналу.

## Проверка публикации

Текущие запуски: https://github.com/Bogolubov-creator/profession-navigator/actions

Внешняя проверка выполняется после завершения публикации:

```sh
QA_URL=https://bogolubov-creator.github.io/profession-navigator/ node scripts/pages-browser-qa.js
QA_URL=https://bogolubov-creator.github.io/profession-navigator/ node scripts/layout-browser-qa.js
```

Первый сценарий открывает каждую опубликованную страницу и сравнивает скачанные формы с исходниками. Второй проверяет 14 направлений и явное переключение версий. Для этих проверок на машине разработчика нужен полный закрытый комплект. Результаты записываются локально в work/. Секреты в отчёты не выводятся.

Платёжный провайдер не подключён. Подписочный доступ выдаётся администратором на срок по заявке. Для промышленного запуска остаются размещение сервера и данных, политика и сроки хранения, утверждённые оператором, а также проверка на физических мобильных устройствах.
