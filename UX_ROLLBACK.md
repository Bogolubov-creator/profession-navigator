# Изменения пользовательских сценариев от 23 сентября 2026 года

До начала работы создан тег `ux-before-2026-09-23` (коммит `4ae96265`) и автономная копия истории `work/ux-before.bundle`.
Резервная копия: `work/ux-backup-2026-09-23`. В ней согласованный снимок SQLite, исходные материалы и загрузки, локальные реквизиты входа и лента изменений. Контрольные суммы записаны в `checksums.json`. Не публиковать папку `work`.
Восстановление исходной базы и материалов проверено в отдельной папке `work/ux-restore-check`.

## Безопасный запуск прежней версии отдельно

Выполнять из корня репозитория. Пути назначения должны быть свободны.

```sh
git worktree add --detach ../navigator-rollback ux-before-2026-09-23
npm run restore -- work/ux-backup-2026-09-23 ../navigator-rollback/private
cd ../navigator-rollback
npm ci
npm run build
PORT=4318 CHANGES_AUTO_SYNC=0 npm start
```

Прежняя версия будет на http://127.0.0.1:4318. Действующую базу этот способ не заменяет. Новые вопросы и редакторские правки, сделанные после резервного копирования, остаются в основной версии. Перед заменой основной версии сделать новую резервную копию.

Для отката публичного интерфейса отменить коммит UX через `git revert`, отправить коммит в `main` и дождаться успешной публикации Pages. Базу данных для отката зеркала восстанавливать не нужно.

## Устройство изменений

Поиск работает по опубликованным доступным материалам, учитывает небольшой словарь близких формулировок и выводит инструкции, документы, затем пояснения. Это не семантическая модель. Документы, прикреплённые к найденной инструкции, включаются в выдачу.
Главная профессии содержит задачи из каталога, продолжение серверного прогресса, последние инструкции на текущем устройстве и тематическую подборку изменений. Частотность задач не измеряется.
Краткое начало берётся из существующих полей. Если редактор не указал отдельный результат, показывается последнее действие инструкции под соответствующим названием. Пропуски явно обозначены.
Пояснения к существующим прикреплённым документам можно заменить в редакторе каждого шага. Для новых файлов поля заполняет редактор. Перечень полей шаблона не выдается за исчерпывающие требования закона.
Контекст вопроса сохраняет ID, название, версию и снимок шага на сервере; проверяются права, номер шага и совпадение версии. Переход через вход сохраняет контекст.
Связи с правовыми изменениями заполняются вручную: публикация, основание проверки, действие, состояние инструкции. Сервер фиксирует редактора и дату. Удаление связи и восстановление карточки доступны через историю версий. Автоматических утверждений о влиянии нормы нет.
На телефоне дополнительные фильтры свернуты, положение списка сохраняется в пределах вкладки. Компактный режим вороны сохраняется на устройстве.

Зеркало остаётся доступным только для чтения. Отправка вопросов, изменение карточек и синхронизация личного прогресса работают на локальном сервере.
